# Willow & Wing Farm

A responsive, single-page chicken shop built with vanilla HTML, CSS, and JavaScript. Open `index.html` in a modern browser to explore the catalog.

## Included

- Chicken catalog with 4-month, 5-month, and 6+-month age filters, search, availability, and individual product details.
- Farm dashboard to add, edit, categorize, and remove listings and manage prices, availability, and stock.
- Responsive layouts for mobile, tablet, and desktop.

The chicken catalog is stored in browser `localStorage`. Dashboard changes only exist in the current browser; this demo does not include a shared backend or administrator authentication. The four named breed listings use photos from the project’s `Image` folder. Other farm photos and web fonts load from external providers.
